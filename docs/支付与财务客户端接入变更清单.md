# 支付与财务：客户端集成交接清单

更新日期：2026-10-19。普通未支付订单不再阻塞其他套餐、模式或渠道；同一次购买更换选择时使用新幂等键，并传可选 `replaces_order_no`。新单建立后后台异步关闭旧单；旧单若付款，保留收款但不重复履约。完整可转发示例见[客户端收银台换套餐与支付切换接入说明](客户端收银台换套餐与支付切换接入说明.md)。其他参数以[客户端集成文档](客户端集成文档.md)为准；所有路径统一加 `/api/v1`，使用客户端用户 Token。

## 对比早期“跳转支付页面”的接法

| 变化 | 集成同事需要做什么 | 文档位置 |
| --- | --- | --- |
| 官方扫码收款 | 支付宝当面付 `qr_code`、微信 Native `code_url` 均由后端放入 `pay_url`。客户端画二维码，不再画工作台或网页网关链接；移除“复制支付链接”按钮 | 7.2 |
| 渠道资格与查单 | 先读 capabilities，只显示 enabled 且 configured 的渠道；下单、重试幂等、查单、过期处理闭环，只有 paid 才确认成功 | 7.2、7.5 |
| 订单记录 | 增加个人订单分页/筛选及详情，页面命名“订单记录”；支付查单用字符串 order_no，财务详情用数字 order_id | 7.4、附录索引 55/56 |
| 退款状态和权益 | 同时展示支付、退款、履约三种状态。全额退款可能保留权益，也可能终止。无客户端直接退款 API，售后走反馈工单 | 7.4、7.5 |
| 升级积分规则 | 已到账积分保留；低等级旧套餐未发放批次停止；同套餐续费顺延。显示新账本类型 subscription_upgrade（金额 0，非扣费） | 7.1 |
| 无需退出重登 | 支付/退款后刷新订阅、积分、流水、订单及 /client/user/me 全局资料；前台定期和窗口恢复时刷新 | 7.2、12.1 |
| 积分到账消息 | 识别 message_type=credit_grant，显示来源、金额和实际到账/抵扣说明；进入积分页，支持未读、详情和已读回执 | 12.1 |

## 必须接入的接口

| 用途 | 接口 |
| --- | --- |
| 商品与价格 | GET `/client/billing/catalog` |
| 订阅 / 积分 / 流水 | GET `/client/billing/subscription`、`/client/billing/account`、`/client/billing/ledger` |
| 全局用户资料 | GET `/client/user/me` |
| 收款渠道能力 | GET `/client/payment/capabilities` |
| 创建订单 | POST `/client/payment/orders`（成功 HTTP 201；金额由服务器计算） |
| 查询支付状态与官方付款码 | GET `/client/payment/orders/{order_no}` |
| 取消本人未付款订单 | POST `/client/payment/orders/{order_no}/cancel`；可选 JSON `{"reason":"用户取消购买"}`；200 `closed` 才重置购买，202 保留原单查状态，409 已付款不退款 |
| 订单记录 / 详情 | GET `/client/finance/orders`、`/client/finance/orders/{order_id}` |
| 消息 / 已读 | GET `/client/user-operations/messages`、PATCH `/client/user-operations/messages/{delivery_id}/read`、POST `/client/user-operations/messages/read-all` |
| 退款诉求转售后 | POST `/client/user-operations/tickets`，按文档反馈协议接入 |

提现、收款账户、邀请奖励与积分转赠按产品需要接入第 10～11 节，不能用收款 capabilities 代替 payout capabilities。财务概览、对账、退款审批、渠道配置及消息投递管理属于运营端，不要求客户端重做。

- 补入附录接口总索引 55/56，以及财务订单列表/详情完整结构示例；增加第 7.5 节客户端联调要点和管理端边界。

## 验收与发布

至少覆盖：小额扫码支付、重复查单不多发积分、补偿退款保留权益、退订退款恢复有效旧套餐或无订阅、升级仅发新套餐计划积分、支付后全局套餐自动刷新、每日登录奖励到账消息及已读。

退款恢复原套餐不延长原期限，也不补发升级时已取消的旧批次。微信产品/商户参数未就绪前不能宣称可收款；自动续费签约暂不支持，下单固定 `auto_renew=false`。

运营端 Docker 部署只发布运营后端和运营 Web。客户端代码需单独更新/打包发布，不会随运营端部署自动替换用户已安装程序。新增 `20261014_payment_cancel` 迁移保存关单请求时间；先备份、迁移并发布后端，再由客户端接入取消入口。运营关单 API 为 `POST /finance/orders/{order_id}/close`，必填原因，使用运营订单核验写权限，客户端不可调用。
