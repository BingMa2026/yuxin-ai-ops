# 定价策略维护

- 定价策略列表提供查看、编辑、上架/下架、删除操作。查看和编辑直接显示，上架/下架及删除位于“更多”菜单。
- 执行中的策略先下架再编辑或删除。删除采用软删除，已有订单及权益继续使用购买时的定价快照。
- 付费刊例执行价按折扣计算并四舍五入到分，允许模型成本 = 执行价（元）×（1 − 目标毛利率）。
- 零元刊例可在策略表格的“允许模型成本（元）”填写大于 0 的预算；未填写时沿用产品刊例的“零元项目允许成本（元）”。策略预算仅作用于当前策略，不覆盖产品刊例预算。
- 购买类型“全部”保存后拆为首购和续费，分别按对应刊例价格计算。查看显示保存时的数值，编辑按当前刊例价格预览。
- 策略详情 `GET /api/v1/operations/billing/catalog/strategies/{id}` 使用原有查看权限；`PUT` 修改、`DELETE` 删除与新建/上下架统一使用 `workspace:budget:pricing:create` 维护权限，均按当前客户端隔离。
- 本次复用现有策略项成本字段和软删除字段，无需数据库结构迁移。

## 当前在售价与客户端

- 模板维护入口：选择版本后可“编辑版本”或“复制为新版本”。抽屉左侧为基本信息、通用规则和套餐目录，点击套餐直接切换，右侧按套餐与价格、积分释放、服务权益分栏，保存按钮固定在底部。价格以元录入，接口仍以分传输。
- 草稿、已发布、已归档版本均可编辑，保存保留原发布状态；套餐按编码更新并保留已有刊例关联，移除套餐不会删除已有刊例。编辑已发布版本的通用规则可能影响使用该版本的业务，积分扣减顺序仍为全平台生效。
- 复制仅创建草稿；草稿和已归档版本都显示“发布版本”，可重新发布旧版本。点击发布才会自动归档全平台原已发布版本。价格体系仍是平台共享模板，本次没有改为按客户端隔离。
- 草稿和归档版本提供删除确认，已发布版本不可删除；仍有关联刊例或定价策略的版本会拒绝删除。删除版本及模板均采用软删除，已使用的版本号保留，不可重复创建。`DELETE /api/v1/operations/billing/pricing/versions/{id}` 与编辑共用 `workspace:budget:price:create` 维护权限，后端独立校验状态与关联数据。
- 模板编辑器不提供生效起止时间；套用模板后的刊例表单也移除“生效区间”输入。新建刊例默认不设时间区间，历史刊例已有时间配置保留；套餐权益周期与积分有效期继续保留。
- 套用模板会同步等级、权益说明及释放账户，旧模板缺少账户时按订阅/积分包补为当期权益/流量积分包；编辑刊例不会反向修改模板。保存失败保留表单，由请求层显示业务错误，不再额外报组件异常。
- 刊例编码仅在同一客户端的未删除记录中唯一；迁移 `20260909_catalog_codes` 将原唯一约束替换为条件唯一索引，允许删除后重新套用同名模板，历史刊例及订单关联保留。价格体系版本号仍全平台唯一，套餐模板编码仅在所属价格版本内唯一。
- 模板修改首购价格后，总积分默认按「首购价（元）×每元兑换积分」计算并四舍五入为整数，随后均分到现有释放批次。修改总积分、增加或移除批次也会重新均分，余数从前往后补 1，例如 99 分 4 批为 25、25、25、24。批次日期及账户保持原配置，均分后仍可手动调整。零元体验套餐保留手工配置的积分，打开已有模板不触发重算；兑换比例变更只更新仍使用旧默认换算值的付费套餐，保留自定义总积分。
- 价格体系模板提供新建刊例的初始配置；已有刊例单独保存价格及权益，发布模板不会自动覆盖它们。价格体系还提供刊例默认毛利规则，当前已发布版本的积分账户优先级参与扣减顺序。

- 价格体系为单一预览页面：左侧版本列表，右侧展示所选版本关联的在售刊例，按通用首购匹配当前生效的全部用户策略。没有关联在售刊例时显示空状态，不用模板价格冒充实际售价。草稿版本在相同布局中展示模板配置并标注尚未发布，保留编辑、发布入口。
- `GET /api/v1/operations/billing/pricing/preview` 与 `/api/v1/client/billing/catalog` 共用计价逻辑。页面固定展示通用首购，移除顶部对象筛选、说明区和双页切换。API 仍支持 `purchase_type` 或当前客户端的 `user_id` 供定向核验；通用预览只命中“全部用户”的策略。
- 续费仅限用户原来的同一刊例；升级到其他刊例使用目标刊例首购价，积分包按单次首购计价。例如企业版首购 499 元、手动续费 399 元，专业版升级企业版并命中首购 0.9 系数时应付 449.10 元，不是 399 元。
- 报价返回 `purchase_type`、`base_price_fen`、`effective_price_fen`、`discount_amount_fen`、策略名称和版本。客户端不再猜测折扣基数，卡片与付款确认都使用服务端报价，创建订单后以订单金额为准。
- 修改刊例后，新报价按当前刊例金额和生效策略系数重算；历史订单、权益仍按原快照。保存为草稿或尚未到生效时间的策略不会改变客户端价格。
- 修改完成后，上架刊例及策略并确保生效时间包含当前时间。进入价格体系并选择对应版本，或点击右上角“刷新”即可验证；客户端重新进入订阅页、回到窗口或点击“刷新”会获取最新报价。仅刷新不会让草稿自动生效。
- “手动续费基价”“续费系数”是定价参数，不是自动扣款开关；当前支付渠道不支持自动扣款，客户端下单固定传 `auto_renew: false`。

验证：在 `backend/` 执行 `uv run pytest tests/test_pricing_strategy_management.py tests/test_billing_credits.py -q`；在 `frontend/web/` 执行 `pnpm type-check`、`pnpm test`、`pnpm build`。
