# 运营平台首发 MVP 验收矩阵

本文用于上线前逐项签字。状态只使用“已自动验证 / 待真实环境验证 / 明确延后”，不以演示数据代替验收。

## 1. 已自动验证

| 领域 | 验收项 | 证据 |
| --- | --- | --- |
| 客户端边界 | 运营令牌携带当前 `app_id`；切换时换发令牌；业务接口不接受前端自报作用域 | 后端隔离测试与鉴权测试 |
| 入口 | 客户端切换器位于顶栏头像前；未选择时仅显示“选择客户端”；无“全部客户端” | 组件结构与前端构建 |
| 默认客户端 | 客户端支持显示排序；登录后按“排序、ID”自动选择第一项 | 后端排序与登录集成测试 |
| 切换保护 | 打开客户端相关编辑器时记录未保存状态，切换前二次确认，切换后清理请求、页签和字典缓存 | 客户端作用域 store 单测与切换器组件 |
| 人员授权 | 客户端可绑定运营人员，普通人员只能访问获授权客户端 | 客户端授权接口与越权测试 |
| 用户账户 | `client_user` 与 `sys_user` 分表；注册、登录、刷新、退出、停用、临时密码可用 | 客户端认证与用户管理集成测试 |
| 认证安全 | 注册/登录按客户端、IP、账号限流；成功、失败和限流事件不记录密码或令牌 | `client_auth_event` 模型、认证服务与迁移 |
| 用户运营 | 表格组合筛选、快捷分群、资料编辑、标签、积分调整和详情聚合；列表遵循系统搜索栏、工具栏、列设置和分页规范 | API 类型检查、前端类型检查与构建 |
| 价格体系 | 平台价格模板与版本独立于客户端刊例；发布模板不会改写已存在刊例 | 计费服务测试 |
| 刊例与策略 | 刊例、首购/续费/通用策略按当前客户端隔离，重叠生效受约束 | 计费服务测试 |
| 支付授权 | 平台渠道启用与客户端授权分离，两者缺一不可 | 支付渠道服务、迁移与订单查询条件 |
| 支付闭环 | 订单快照、幂等、回调验签、身份/币种/金额校验、主动查单补偿及尝试审计 | 支付单元测试与计费集成测试 |
| 订阅积分 | 支付后生成订阅周期和积分批次；余额、预占、结算、退回、过期和人工调整有不可变流水；周期任务补偿到期、释放和陈旧预占 | 计费集成测试与调度注册 |
| 使用资格 | 订阅不是额外开关；有有效积分且模型路由有效即可使用；额度不足以覆盖请求上限时自动压低输出预算 | 模型网关预占逻辑与测试 |
| 模型资源 | 供应商模板/账号、模型目录、客户端绑定和业务路由均由运营端维护；菜单指向真实管理组件 | 模型管理接口、菜单校准与隔离测试 |
| 客户端模型 | 客户端仅展示运营端下发的脱敏只读配置，不再编辑供应商密钥 | 客户端契约测试、类型检查与构建 |
| 流式体验 | OpenWorker 使用短时运行令牌调用 SSE；运营端复用供应商 HTTP 连接；断开或失败会结算/退回预占 | 网关连接池、网关与 OpenWorker 测试 |
| 遥测 | SQLite outbox、幂等批量上报、指数退避和字段白名单；不上传正文、提示词、文件名、路径或密钥 | 遥测测试与白名单校验 |
| 菜单范围 | 经营概览隐藏、全部资源移除、商机资源只展示真实空状态 | 初始化逻辑与前端构建 |
| 数据库 | 开发环境已升级到 `20260903_client_app_order`；空库升级、回退最后一版、再次升级成功 | 实际迁移与 Alembic 演练 |

## 2. 待真实环境验证（上线阻断）

| 领域 | 必须提供/执行 | 通过标准 |
| --- | --- | --- |
| 微信支付 | 已获批的 AppID/商户号、商户私钥、APIv3 密钥、平台证书或微信支付公钥、公网 HTTPS 回调地址 | 最小金额下单成功；回调验签成功；重复回调不重复发权益；人为阻断回调后主动查单能补偿 |
| 支付宝 | 已签约的应用 ID/卖家 ID、应用私钥、支付宝公钥、公网 HTTPS 回调地址 | 最小金额下单成功；回调与主动查单验签成功；金额和卖家身份一致；权益只发一次 |
| 模型供应商 | 至少一个真实供应商账号、模型和客户端业务路由 | 普通与流式调用成功；首字延迟可接受；停止生成、供应商失败与回退时积分账实一致 |
| 视觉回归 | 用户明确选择 Codex 内置浏览器或 Chrome | 浅色/深色、桌面宽屏和 375px 下，参考图与实现同屏比较后无阻断级布局问题 |
| 灰度观察 | 一个内部客户端及真实测试用户 | 订单、积分、模型用量和遥测连续观察无串数据、重复计费或明显错误率异常 |

## 3. 明确延后

- 经营概览和跨客户端经营分析。
- 自动续费签约、扣款、重试、解约和通知；首发只支持一次性支付与手动续费。
- 审批流、动态产品能力/成果配置、自动分群规则引擎和营销触达。
- 商机资源后端、全部资源统一搜索、发票、退款和自动对账单。

只有第 2 节全部通过，且生产 `SECRET_KEY`、数据库、Redis、证书与密钥已完成备份和恢复演练，才能把首发状态标记为“可正式上线”。
