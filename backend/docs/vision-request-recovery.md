# 视觉请求的恢复诊断

非流式 runtime/complete 上游失败响应在原有 code、msg 基础上，新增可选的
`data.upstream_diagnostic`，只包含 reason、fields、error_code 白名单事实。
不返回供应商原始消息、响应正文、密钥或内部堆栈。旧客户端可忽略新增字段。

客户端可据此区分明确的配置错误与原因不明确的参数拒绝，并判断是否有
response_format 相关证据。fields 仅表示被提及字段，不单独证明该字段非法。
服务端不自动重发被拒绝请求；客户端承担有限次数的页面重试预算。

上线顺序：先更新运营端诊断契约，再更新客户端。旧运营端没有诊断字段时，
新客户端仅对不明确的50201作一次原参数重试，不猜测是否应切换响应格式。

验证：pytest tests/test_gateway_error_diagnostics.py -q。测试使用模拟供应商、
模拟结算及隔离结果日志，不访问真实供应商或业务数据库。
